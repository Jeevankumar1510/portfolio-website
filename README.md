# Jeevan Kumar — 3D Interactive Developer Portfolio

> Futuristic, high-performance 3D personal developer website for **Jeevan Kumar (Jiyyani Jeevan Kumar)** — AI Engineer | Machine Learning | Generative AI & Cloud.

---

## ⚡ Highlights & Key Features

- **3D Evolving Skills Galaxy (`TechSkills.jsx` & `EvolvingSkillsCanvas.jsx`)**:
  - Interactive multi-orbital planetary system with 5 concentric orbital planes and 15+ evolving skill nodes.
  - Dedicated interactive nodes for **AI, LLMs, Gen AI, Agentic AI, ML, Deep Learning, Django, FastAPI, AWS, Azure, PyTorch, YOLO, and Data Science**.
  - 360-degree interactive drag rotation, orbit pause/resume controls, real-time raycasting hover inspection, and proficiency meters.
- **3D Developer Core (`HeroCanvas.jsx`)**:
  - Three.js interactive core featuring an inner glowing wireframe icosahedron, tri-axial gyroscope torus rings with satellite nodes, 14 floating polyhedra, and full 360° mouse drag rotation.
- **Dynamic 3D Particle Constellation (`ParticleBackground.jsx`)**:
  - Site-wide background starfield with 850+ depth-sorted particles reacting to cursor velocity and scroll parallax.
- **3D Timeline & Interactive Cards**:
  - **Education**: Vertical glowing timeline with 3D perspective mouse tilt and CGPA performance gauges (GIET CSE: 8.12, M.R.A.G.R: 8.84, AP Model: 9.5).
  - **Internships**: 3D 180° Flip Cards for Techwing (AWS Cloud) and Blackbucks (AI/ML & Data Science) revealing duties and tech stacks on flip.
  - **Projects**: 3D tilt cards with category filtering, modal inspector, GitHub links, and live demo buttons.
  - **Certifications**: 3D glassmorphism cards for AWS Certified Cloud Practitioner and Azure AI Fundamentals (AI-900).
- **Cyberpunk UI & Glassmorphism**:
  - Dark theme (`#030712`) accented with neon cyan (`#00f0ff`), electric blue, and cyber purple (`#a855f7`).
- **Audio Synthesizer (Web Audio API)**: Zero-latency sci-fi sound effects on hover, click, and form actions with a navbar toggle.
- **Validated Contact Form**: Instant feedback, neon focus glows, one-click copy for email and phone, and celebratory confetti.

## 🚀 Getting Started

To run the development server locally:

```bash
npm run dev
```

The portfolio will be live at: `http://localhost:3000`

To build for production:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
